📋 STEP 1: GENERATE KEYSTORE
────────────────────────────────────────────────────────────
cd android
./generate-keystore.sh

OR manually:
cd android/app
keytool -genkey -v -keystore iqra-release-key.jks \
  -storetype JKS -keyalg RSA -keysize 2048 \
  -validity 10000 -alias iqra-key-alias


📝 STEP 2: CREATE key.properties
────────────────────────────────────────────────────────────
Create: android/key.properties

storePassword=YOUR_PASSWORD_HERE
keyPassword=YOUR_PASSWORD_HERE
keyAlias=iqra-key-alias
storeFile=app/iqra-release-key.jks

⚠️  Replace YOUR_PASSWORD_HERE with actual passwords!


🏗️  STEP 3: BUILD RELEASE
────────────────────────────────────────────────────────────
For APK (direct install):
  flutter build apk --release

For App Bundle (Google Play):
  flutter build appbundle --release


✅ VERIFICATION
